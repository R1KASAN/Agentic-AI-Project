## Getting Started (5-Minute Overview)

### What W06 Does

Every school morning at **7:30 AM (M-F)**, an autonomous agent:
1. Aggregates student mood check-ins from past 24h (k-anonymity k≥3)
2. Analyzes classroom climate trend vs. baseline
3. Generates 1-2 teaching suggestions via Gemini LLM
4. Sends briefing to teacher via LINE (with approval CTAs)
5. Logs all decisions to audit trail (for transparency)
6. Tracks teacher response (approval/dismissal/implementation)

### Why It Matters (Loop Closure)

- **Sense** (Loop0): Students submit moods
- **Reason** (Loop2): Agent evaluates + recommends
- **Act** (Loop3): Sends LINE briefing
- **Learn** (Loop4-5): Tracks what works; adapts next cycle

### Step 2: N8N Workflow Setup (45 min)

**Location**: `n8n/workflows/006-morning-briefing.workflow.ts`

**Nodes** (5 main + 3 tools):
1. **Schedule Trigger** — `0 7 * * 1-5` (7:30 AM M-F)
2. **Check School Day** — IF node: calendar guard
3. **Loop Over Classes** — For each active class
4. **Get Climate Summary** — RPC call (tool sub-workflow)
5. **LangChain Agent** — Gemini + tool isolation
6. **Prepare LINE Message** — Template formatting
7. **Send LINE Notify** — POST to LINE API
8. **Create Recommendation** — DB insert
9. **Log Audit** — Decision path audit
10. **Update Dashboard** — Webhook revalidation

**Sub-Workflows** (tool isolation):
```
tool-get-class-climate-summary/
  → calls get_class_climate_summary(class_id, '24h') RPC
  → returns {mean_mood, std_dev, n_students, k_anonymity_safe}

tool-get-past-recommendations/
  → queries recommendations table (past 7 days)
  → calculates closure_rate, approval_rate

tool-get-teacher-action-rate/
  → fetches teacher_profiles metrics
  → checks is_inquiry_mode status
```

**LLM Config**:
```json
{
  "model": "gemini-2.0-flash",

  "topK": 3,
  "systemPrompt": "Analyze mood data and suggest ONE teaching intervention...",

}
```

## Architecture Quick Reference

### Decision Gates (All Logged)

```
W06 Schedule Trigger (7:30 AM M-F)
  ↓
[1] Is school day? (check school_days table)
  NO → SKIP (log reason: holiday)
  ↓ YES
[2] Are there ≥3 students with mood check-ins in past 24h?
  NO → SKIP (log reason: insufficient_data)
  ↓ YES
[3] Has teacher already received <2 briefings today?
  NO → SKIP (log reason: frequency_limit)
  ↓ YES
[4] Is teacher available? (availability_status != 'on_leave')
  NO → SKIP (log reason: teacher_unavailable)
  ↓ YES
[5] LLM generates recommendation, confidence ≥ 0.65?
  NO → Use fallback (rule-based), log confidence<0.65
  ↓ YES
[6] Send LINE briefing + create recommendation record
  → Log decision path to n8n_audit_log
  → Webhook to update dashboard
```

### Loop Closure Path

```
Teacher Receives Briefing (Loop3)
  ↓
Teacher Approves (Loop4: sense feedback)
  UPDATE recommendations.teacher_approval_status = 'ACKNOWLEDGED'
  ↓
Teacher Implements in Class
  UPDATE recommendations.teacher_implemented_at = NOW()
  UPDATE recommendations.teacher_feedback = "..."
  ↓
Analytics Aggregation (Loop5: learn + adapt)
  UPDATE teacher_profiles.closure_rate_7d = ...
  If action_rate < 20% for 2 weeks: set is_inquiry_mode = true
  ↓ Next W06 cycle
  Agent adapts: uses updated metrics for tone/frequency
```

## Debugging Checklist

### Briefing Not Sent?

Check in order:
1. **n8n Workflow Status**: Is W06 active? Did schedule trigger fire?
   - Open n8n UI → W06 workflow → check execution logs
   
2. **School Day?**: Is today marked as school day?
   ```sql
   SELECT * FROM school_days WHERE date=TODAY() AND school_id=X;
   ```
   
3. **K-Anonymity**: Were there ≥3 students with moods?
   ```sql
   SELECT COUNT(DISTINCT student_id) FROM student_pulses
   WHERE class_id=X AND created_at > NOW()-24h;
   ```
   
4. **Frequency Guard**: Did teacher already get 2 briefings today?
   ```sql
   SELECT COUNT(*) FROM n8n_audit_log
   WHERE workflow_id='W06' AND teacher_id=X
   AND DATE(timestamp)=TODAY();
   ```
   
5. **Audit Log**: Check `n8n_audit_log` for decision path + error:
   ```sql
   SELECT decision_path_json, action_taken, skip_reason
   FROM n8n_audit_log
   WHERE workflow_id='W06' ORDER BY timestamp DESC LIMIT 1;
   ```

### Teacher Not Seeing Dashboard Widget?

1. **Cache**: Did ISR revalidation trigger?
   - Check n8n webhook completion log
   - Manually click [Refresh] in UI
   
2. **RLS**: Can teacher see their own class?
   ```sql
   SELECT * FROM recommendations WHERE class_id=X;
   -- If no results, RLS might be blocking
   ```
   
3. **API Route**: Is `/api/teacher/briefing-status` working?
   ```bash
   curl http://localhost:3000/api/teacher/briefing-status?class_id=X
   ```

### LINE Message Not Received?

1. **API Error**: Check n8n workflow logs for LINE Notify POST error
2. **Token**: Is `teacher_profiles.line_notify_token` valid?
3. **Message**: Is briefing_message empty/malformed?
4. **Fallback**: Email should have been sent instead (check inbox)

## Agentic Loop Alignment

**W06 implements Loops 2, 3, and 4 of the 5-step agentic cycle**:

| Loop | Phase | W06 Component | Acceptability |
|------|-------|--------|------|
| **Loop0** | Sense | Student submits mood (via W01) | ✅ Sense complete |
| **Loop1** | Memory | Fetch historical trends (via tool-get-past-recommendations) | ✅ Context loaded |
| **Loop2** | Reason/Plan | LangChain Agent evaluates climate → selects policy (ROUTINE/WARNING) → LLM generates rec | ✅ Agentic reasoning |
| **Loop3** | Act | Send LINE briefing + create recommendation record | ✅ Action taken |
| **Loop4** | Self-Evaluate | Teacher approves/implements; feedback logged | ✅ Learns from response |
| **Loop5** | Adapt | Dashboard analytics; closure rate calculated; next cycle uses updated metrics | ✅ Adapts over time |

**Non-Negotiable Properties**:
- ✅ Deterministic decision path (all gates logged)
- ✅ Tool isolation (LLM can't directly query raw data)
- ✅ k-anonymity enforced (k≥3 at RPC layer)
- ✅ Human-in-the-loop (teacher approval gate required)
- ✅ Loop closure tracking (implementation rate measured)
