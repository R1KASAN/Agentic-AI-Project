# Climate Agent UX/UI Prompt

Use this prompt when generating high-fidelity design mockups for Climate Agent. It is tuned for the teacher and student dashboard family in this repo and keeps the visual language cohesive across all screens.

```text
Climate Agent, a privacy-first classroom climate platform for teachers and students.

Create a cohesive high-end UX/UI system for Climate Agent across all main screens, including:
- Teacher Dashboard
- Class Climate overview
- Class detail / recommendation workflow
- Student Classes
- Student Feedback
- Student Check-in

The design should feel like one unified product family with consistent layout, spacing, color behavior, typography, and component styling across teacher and student views.

Visual direction:
premium, modern, editorial, calm, trustworthy, polished, production-ready.
Minimal but not plain. Clean but not sterile. Professional but warm.
The UI should feel like a real SaaS product used in schools every day.

Color system:
use a harmonious, modern palette with strong contrast and excellent readability.
Teacher surfaces should feel more authoritative and structured.
Student surfaces should feel softer and more inviting, but still part of the same system.
Use:
- primary accent: confident sapphire / blue
- secondary accent: calming indigo / slate
- success: soft green
- warning: warm amber
- danger: muted red
- background: deep navy or soft off-white depending on screen type
- text: always high contrast and readable on light surfaces
Avoid low-contrast beige-on-cream combinations.
Avoid muddy colors, neon colors, and generic purple gradients.

Accessibility:
all text must have WCAG AA contrast ratio 4.5:1 or higher.
No overlapping text.
No text too close to background.
No low-contrast labels.
Make every label, badge, and helper text clearly readable on mobile and desktop.

Typography:
modern sans-serif such as Geist, Inter, SF Pro, or Roboto.
Use strong hierarchy:
- large editorial headings
- clear section labels
- readable body text
- compact metadata
- crisp button text
Use comfortable line height and subtle letter spacing.
No decorative or overly stylized fonts.

Teacher dashboard style:
structured, analytical, and calm.
Use clear status cards, risk badges, summary metrics, class cards, and action areas.
Make the dashboard feel like a smart briefing room for teachers.

Student dashboard style:
lighter, safer, more approachable.
Show clear class cards, feedback areas, and check-in actions.
Make it feel reassuring, simple, and easy to use.
Preserve privacy-first messaging and avoid raw student data.

Layout rules:
- generous white space
- clean alignment
- strong visual hierarchy
- soft elevation and subtle shadows only
- rounded but disciplined card shapes
- consistent spacing scale
- distinct primary actions and secondary actions
- no clutter
- no overlapping elements
- no busy decorations

Component language:
- navigation sidebar
- hero header
- status chips / risk badges
- class summary cards
- trend / climate insight cards
- feedback summary blocks
- action panels
- privacy-safe empty states
- confirmation dialogs

Mood:
trustworthy
academic
calm
high-end
clear
human
privacy-first
professional

Composition:
design as a polished multi-screen product mockup that shows both teacher and student views as part of the same system.
Make the system feel cohesive, premium, and thoughtfully engineered.

Important:
This should look like a real climate/education SaaS product, not a generic dashboard.
The interface must feel distinctive, modern, and highly usable.

--ar 16:9 --stylize 250 --v 6
```

## Quick Notes
- Keep teacher pages slightly more structured and analytical.
- Keep student pages lighter and more reassuring.
- Use one shared design language so the product feels like a single system.
- Prioritize contrast, whitespace, and readable typography over decoration.
